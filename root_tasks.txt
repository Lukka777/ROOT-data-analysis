ROOT – завдання для практики
=============================

Етап 1. Базові об’єкти ROOT
---------------------------
  1. Hello ROOT!
     - Створити просту гістограму (TH1F).
     - Вручну заповнити її кількома числами (Fill).
     - Намалювати.

  2. Випадкові числа
     - Згенерувати 100 000 випадкових чисел із гаусівського розподілу.
     - Побудувати гістограму.
     - Накласти на неї теоретичну функцію (TF1).

Етап 2. Основи статистики
-------------------------
  3. Монетка
     - Симулювати 1000 підкидань монетки.
     - Побудувати гістограму кількості «орлів» і «решок».
     - Порахувати відхилення від очікуваного 50/50.

  4. Суміш розподілів
     - Згенерувати суміш двох гаусів з різними середніми.
     - Побудувати гістограму.
     - Накласти відповідну функцію TF1, відновити параметри обох розподілів.

Етап 3. Робота з файлами та деревами
------------------------------------
  5. Читання даних із текстового файлу
     - Є файл data.txt з енергіями.
     - Завантажити числа у TTree.
     - Зберегти дерево в ROOT-файл.
     - Побудувати гістограму.
     - Обчислити середнє і стандартне відхилення.

  6. Запис подій у ROOT-файл
     - Згенерувати події зі значеннями: energy, theta, charge.
     - Зберегти у TTree в ROOT-файл.
     - Перевірити, що файл читається.

Етап 4. Багатовимірні розподіли
-------------------------------
  7. 2D-розподіл (корельовані дані)
     - Згенерувати точки (x, y), де y ≈ x + шум.
     - Побудувати 2D гістограму (TH2F).
     - Побудувати профільну гістограму середніх значень <y>(x).

  8. Фіт експоненти (час життя частинки)
     - Згенерувати експоненційно розподілені числа.
     - Побудувати гістограму.
     - Виконати фіт функцією exp(-λx).
     - Порівняти відновлений параметр із вихідним.

Етап 5. Кінематика частинок
---------------------------
  9. Дворозпад A → B + C
     - Частинка A з масою 5 GeV розпадається на B (маса 2) та C (маса 1).
     - Згенерувати розподіл енергій B і C у системі центра мас.
     - Побудувати гістограму.

  10. Трирозпад (Dalitz plot)
      - A → B + C + D (усі масless).
      - Згенерувати випадкові події.
      - Побудувати діаграму Далитца: X = m²(BC), Y = m²(CD).

Етап 6. Сучасні інструменти
---------------------------
  11. RDataFrame: селекція подій
      - Завантажити TTree з подіями: візьміть наш файл з ттбар подіями і читайте, наприклад, 4-імпульси топа (mcT).
      - Вибрати лише ті з енергією > 300 GeV.
      - Побудувати гістограму θ для вибраних подій.

  12. RDataFrame: комплексний аналіз
      - Використати той самий TTree.
      - Порахувати середню енергію для подій із зарядом +e та -e окремо.
      - Побудувати асиметрію (N⁺ - N⁻)/(N⁺ + N⁻).
      - (замість +e та -e візьміть спочатку топ і антитоп, а потім лептон+ і лептон-)
